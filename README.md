# Agency AI Engine

**AI-powered client acquisition system for marketing agencies.**

Turn a 2-minute client intake into ready-to-send pitches, proposals, and outreach sequences.

## What's Inside

1. **Intake Form Template** (Notion) — Capture everything you need in 2 min
2. **AI Prompt Library** (7 workflows):
   - Pitch Deck Generator
   - Proposal Writer
   - Cold Outreach Sequences
   - Follow-up Automation
   - Case Study Creator
   - Monthly Report Generator
   - Scope Creep Defender (contract clauses)
3. **Agency Dashboard** (Notion) — Track all clients, proposals, pipeline
4. **Setup Video** — 10-min walkthrough with AI voiceover

## Tech Stack

- Frontend: Next.js + Tailwind (Vercel)
- Payments: Stripe
- Delivery: Notion (template) + Gumroad-style download page
- AI: GPT-4/Claude prompts (user brings own API key)
